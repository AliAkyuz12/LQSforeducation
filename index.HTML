📝 Numerical Methods

🔧 Integrator: RK4 with Projection
This simulator uses 4th-order Runge-Kutta (RK4) integration for the Lindblad master equation:

ρ(t+Δt) = ρ(t) + (Δt/6)·(k₁ + 2k₂ + 2k₃ + k₄)

After each step, projection is applied to enforce:
• Trace = 1 (normalization)
• Hermiticity: ρ = ρ†
• Positivity: ρii ≥ 0
⏱️ Time Step Selection (CFL-like)
Adaptive dt based on stability condition:
dt_safe = 0.1 / ω_max where ω_max = max(E_J, N²·E_C) / ℏ

📚 What is Quantum Tunneling?

Wave function penetrates the barrier!
1 Classical Physics: A particle cannot pass a barrier higher than its energy. A ball cannot roll over a hill.
2 Quantum Mechanics: The wave function decays exponentially inside the barrier, but never reaches zero!
3 Tunneling: There is a probability of finding the particle on the other side of the barrier.

🔑 Key Concepts

EJ (Josephson Energy): Cooper pair tunneling energy
EC (Charging Energy): Quantum fluctuation scale
Decoherence: Quantum information loss
Density Matrix (ρ): Describes mixed states

$$i\hbar\frac{\partial}{\partial t}|\psi\rangle = \hat{H}|\psi\rangle$$

$$\frac{d\rho}{dt} = -\frac{i}{\hbar}[H,\rho] + \sum_i \left(L_i\rho L_i^\dagger - \frac{1}{2}\{L_i^\dagger L_i, \rho\}\right)$$

$$\Gamma = \frac{\omega_p}{2\pi} \exp\left(-\frac{36 E_J}{5\hbar\omega_p}\Delta V^{3/2}\right)$$
